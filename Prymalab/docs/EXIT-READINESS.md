# Scale and exit-readiness plan

## Target ownership model

Form a legal entity and make it the single owner/controller of the domain, GitHub organization, Vercel team, Supabase organization, production email, analytics, Search Console, social handles, contracts, content, design files and trademark applications.

Until the entity exists, maintain a signed founder asset schedule. When formed, execute one written assignment covering all pre-incorporation code, design, copy, databases, domains, goodwill and associated rights, subject to counsel review.

## 30-day priority checklist

- [ ] Engage a Vietnam trademark lawyer with international search capability.
- [ ] Decide rebrand versus continued use only after written advice.
- [ ] Form the contracting legal entity and open a company bank account.
- [ ] Move operational accounts to company-owned email addresses with MFA and two administrators.
- [ ] Rotate the exposed admin password and every secret ever shared in chat or screenshots.
- [ ] Sign founder and contractor IP/confidentiality assignments.
- [ ] Complete image/font/software license provenance.
- [ ] Define privacy controller, processing purposes, retention periods and deletion workflow.
- [ ] Add terms that identify the contracting entity before accepting material revenue.
- [ ] Establish database backups and perform a restore test.

## Data-room index

1. Corporate: incorporation, cap table, directors, taxes, banking.
2. IP: assignments, trademark searches/applications, domain records, licenses, asset register.
3. Technology: architecture, repository export, dependencies, security reviews, backups, incidents.
4. Commercial: packages, pricing history, orders, refunds, revenue reconciliation, material contracts.
5. Privacy/compliance: notices, consent evidence, vendor DPAs, retention/deletion records, complaints.
6. People: employment/contractor agreements, IP clauses, access history, termination checklists.
7. Operations: provider ownership, disaster recovery, runbooks, monitoring and support obligations.

## Transfer rehearsal

Quarterly, verify that an authorized buyer could receive without founder-personal dependency:

- repository and deployment control;
- domain and DNS control;
- database backup and schema;
- production secrets through a secure rotation process;
- customer contracts and lawful data-transfer basis;
- all IP assignments and third-party licenses;
- bank/payment reconciliation and tax records;
- documented admin access and disaster recovery.

Any item that requires an undocumented personal login, verbal promise, or missing license is a transaction blocker.
