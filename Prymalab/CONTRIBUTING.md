# Contribution and IP policy

This repository is not accepting external code, design, copy, data, or media contributions by default.

Before any contribution is merged, the contributor must sign a written agreement that:

- identifies the contributor and the exact deliverables;
- confirms the work is original or properly licensed;
- discloses every third-party component and its license;
- assigns transferable intellectual-property rights to the project owner, to the extent permitted by law;
- includes confidentiality and authority-to-sign representations; and
- permits the project owner to modify, commercialize, license, sell, or transfer the deliverables.

A Git commit, pull request, invoice, or payment alone is not treated as a complete IP assignment. The signed agreement and acceptance record must be stored in the project data room before merge.
